Is this your first device?

Qurb keeps your files on devices you own, and moves them directly between them.

Where should your files live?

A folder on this computer. Everything in it becomes part of your Qurb space.

How much space may Qurb use here?

On this computer's disk. You can change it at any time in Storage.

Enter the code from your other device

On your phone, open Qurb, go to Devices, choose Add a device and then Show a code on this phone. Type that code here. It brings your key with it, so there's nothing else to type.

Qurb is locked

This computer's key is protected by a passphrase. Type it to open your files and start syncing.

Forgotten it? Another of your devices can set this computer up again: move this folder's .qurb aside, choose “I already use Qurb”, and type the code that device shows.

You're set up

Next, add your phone or another computer: in Devices, choose Add a device and scan the code.
