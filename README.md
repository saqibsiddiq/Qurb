# Qurb

A multi-platform project skeleton for a cloud control plane, desktop client, mobile native shells, and shared Rust libraries.

## Workspace layout

- `backend/` - Go Cloud Control Plane
- `desktop/` - Rust Desktop Core Client Application
- `mobile/` - Native mobile shell integrations and shared FFI layer
- `shared/` - Shared Rust crates for crypto, protocol, and storage
- `infra/` - Infrastructure as code for container and cloud provisioning
- `docs/` - High-level technical specification documents
